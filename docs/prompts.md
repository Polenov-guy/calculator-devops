# Переиспользуемый запрос и полученный результат

## Запрос для реализации

> Реализуй учебное веб-приложение «Калькулятор» на Go со встроенными HTML/CSS/JS, серверными вычислениями и историей по анонимным сессиям в persistent SQLite. Нужны тесты арифметики, API и сохранности данных; health/readiness/version/metrics; счётчики открытий страницы и вычислений. Подготовь Dockerfile, который упаковывает заранее собранный бинарник, отдельную среду сборки и Docker Compose с Prometheus, Grafana, Node Exporter, cAdvisor и Blackbox Exporter. Dashboard должен создаваться автоматически и показывать использованные/доступные ресурсы, health и открытия за час. Реализуй GitHub Actions: tests/build → сохранение бинарного artifact → отдельный job скачивания и упаковки → GHCR → SSH deploy по digest. Предусмотри persistent volumes, online backup, проверку версии и вычисления после deploy, откат образа и конфигурации при сбое. Дай скрипт подготовки чистой Ubuntu 24.04 amd64 и пошаговую инструкцию настройки GitHub/SSH. Не арендуй сервер и не выполняй на нём deploy. Отдельно перечисли реально выполненные проверки и непроверенные серверные этапы.

## Полученный результат

Создан проект calculator-devops: Go-приложение, frontend, SQLite history, metrics, Docker/Compose, workflow, build/package/deploy/rollback/backup/bootstrap/preflight scripts, provisioned Grafana dashboard, инструкции VPS и основа отчёта. Фактические результаты локальной проверки перечислены в VALIDATION.md. Удалённый repository, опубликованный image и работающий VPS не созданы этим комплектом.

Это нормализованный переиспользуемый запрос, описывающий результат этой сессии, а не дословная полная история переписки.
